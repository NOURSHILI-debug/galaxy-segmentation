# Manifest schema (`dataset/metadata/manifest.csv`)

Generated by `python -m src.data.dataset_index --root dataset/raw [--deep]` (read-only scan; never modifies `dataset/raw/`).

## Filename rule and sample IDs
- Recognized FITS: `imagedata_<ID>.fits` and `mask_<ID>.fits` (`.fits` suffix, case-sensitive prefixes).
- `sample_id` = text after the prefix up to `.fits` (e.g. `imagedata_1-100523.fits` → `1-100523`).
- FITS files not matching these prefixes are not samples; they are listed in `audit_summary.json: unrecognized_fits_files`.
- Non-FITS files are counted in `audit_summary.json: n_non_fits_files`.

## Manifest columns

| Column | Meaning |
|---|---|
| `sample_id` | Sample identifier parsed from filename. |
| `status` | Row status (see below). |
| `image_path` | Image FITS path relative to `--root` (empty if none). |
| `mask_path` | Mask FITS path relative to `--root` (empty if none). |
| `image_n_hdus` | Number of HDUs in image FITS (if readable). |
| `mask_n_hdus` | Number of HDUs in mask FITS (if readable). |
| `image_shape` | Shape of first non-None image HDU data as `HxW`/dims (if readable). |
| `mask_shape` | Shape of first non-None mask HDU data (if readable). |
| `image_hdu_shapes` | `;`-joined shapes of all image HDUs (`None` if no data). |
| `mask_hdu_shapes` | `;`-joined shapes of all mask HDUs. |
| `image_nonfinite` | Count of non-finite pixels across all image HDUs (`--deep` only). |
| `mask_nonfinite` | Count of non-finite pixels across all mask HDUs (`--deep` only). |
| `mask_raw_values` | JSON list of unique raw mask values observed (`--deep` only). |
| `image_error` | Read/parse error for image file, if any. |
| `mask_error` | Read/parse error for mask file, if any. |

- Number of manifest rows == number of unique sample IDs (duplicates produce extra rows but no sample ID is dropped; `n_unique_sample_ids` counted from unique IDs).

## Status meanings

| Status | Meaning |
|---|---|
| `ok` | Matched image+mask pair, both readable, HDU/image-mask shapes consistent. |
| `missing_mask` | Image file exists but no corresponding mask for the sample ID. |
| `missing_image` | Mask file exists but no corresponding image for the sample ID. |
| `duplicate` | Same sample ID appears in more than one image and/or mask file (no rows dropped). |
| `unreadable` | At least one present file could not be read/parsed (see `*_error`); run does not crash. |
| `shape_mismatch` | Readable pair but image HDU shapes differ, or mask shape does not match image shape. |

`audit_summary.json` records totals, per-status counts, shape/HDU distributions, unrecognized/non-FITS counts, and (`--deep`) union of raw mask values and non-finite row counts.
